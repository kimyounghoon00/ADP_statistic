# [[코시-슈바르츠 부등식]] — 한 문장에서 출발하는 사다리

> **한 문장 핵심**: "곱을 더한 것의 크기는, 각자 크기를 잰 뒤 곱한 것을 넘지 못한다."
> $$\left(\sum a_i b_i\right)^2 \le \left(\sum a_i^2\right)\left(\sum b_i^2\right)$$
> 등호는 두 수열이 **비례(한쪽이 다른쪽의 상수배)**할 때만.
---

## 🟢 Level 0 — 중학생: 숫자로 만져보기

두 쌍의 수 $a=(3,4)$, $b=(1,2)$ 를 보자.

- 왼쪽(곱의 합 제곱): $(3\cdot1 + 4\cdot2)^2 = (3+8)^2 = 11^2 = 121$
- 오른쪽(제곱합의 곱): $(3^2+4^2)(1^2+2^2) = (25)(5) = 125$

$121 \le 125$. ✔ 아슬아슬하게 안 넘는다.

언제 **딱 같아질까?** $b$ 를 $a$ 의 정확히 절반 $(1.5,2)$ 로 바꿔보자 — 즉 $b$ 가 $a$ 에 **비례**할 때:

- 왼쪽: $(3\cdot1.5+4\cdot2)^2=(4.5+8)^2=12.5^2=156.25$
- 오른쪽: $(25)(1.5^2+2^2)=25\cdot6.25=156.25$ → **등호!**

> 직관: 두 수열이 "같은 방향"을 가리킬수록 왼쪽이 오른쪽에 가까워지고, 정확히 같은 방향이면 등호.

---

## 🔵 Level 1 — 고등학생: 두 가지 증명

### (a) 판별식 증명 (가장 깔끔한 대수적 증명)

실수 $t$ 에 대한 함수를 만든다. 제곱들의 합이므로 **항상 0 이상**:

$$f(t) = \sum_i (a_i t - b_i)^2 \ge 0 \quad (\forall t)$$

전개하면 $t$ 에 대한 이차식:

$$f(t) = \Big(\sum a_i^2\Big)t^2 - 2\Big(\sum a_i b_i\Big)t + \Big(\sum b_i^2\Big) \ge 0$$

"위로 열린 이차식이 항상 0 이상" ⟺ **판별식 $\le 0$**:

$$\Big(2\sum a_i b_i\Big)^2 - 4\Big(\sum a_i^2\Big)\Big(\sum b_i^2\Big) \le 0$$

$$\therefore \left(\sum a_i b_i\right)^2 \le \left(\sum a_i^2\right)\left(\sum b_i^2\right) \qquad\blacksquare$$

등호 ⟺ 판별식 $=0$ ⟺ 어떤 $t_0$ 에서 $f(t_0)=0$ ⟺ 모든 $i$ 에서 $a_i t_0 = b_i$ ⟺ **$b$ 가 $a$ 에 비례**.

### (b) 벡터·코사인 해석 (왜 "당연한가")

벡터로 보면 $\sum a_i b_i = \mathbf a\cdot\mathbf b$ (내적), $\sum a_i^2 = |\mathbf a|^2$. 그리고

$$\mathbf a\cdot\mathbf b = |\mathbf a|\,|\mathbf b|\cos\theta$$

$\cos\theta\in[-1,1]$ 이므로 $|\mathbf a\cdot\mathbf b| \le |\mathbf a||\mathbf b|$, 제곱하면 코시-슈바르츠. 등호는 $\cos\theta=\pm1$, 즉 **두 벡터가 평행**할 때. → "비례 조건"의 기하학적 정체가 바로 **평행**.

---

## 🟣 Level 2 — 학부 선형대수: 임의 내적공간으로 일반화

이제 $\mathbb R^n$ 을 벗어나 **임의의 내적공간** $(V, \langle\cdot,\cdot\rangle)$ 에서 성립함을 보인다. 정리:

$$\boxed{\ |\langle u, v\rangle|^2 \le \langle u,u\rangle\,\langle v,v\rangle\ }$$

**사영(projection) 증명.** $v\neq 0$ 이라 하자. $u$ 에서 $v$ 방향 성분을 빼낸 잔차

$$w = u - \frac{\langle u,v\rangle}{\langle v,v\rangle}\,v$$

는 $v$ 와 직교한다 ($\langle w,v\rangle=0$, 직접 계산). 내적의 공리상 $\langle w,w\rangle\ge0$:

$$0 \le \langle w,w\rangle = \langle u,u\rangle - \frac{\langle u,v\rangle^2}{\langle v,v\rangle}$$

양변에 $\langle v,v\rangle>0$ 을 곱하면 코시-슈바르츠. $\blacksquare$
등호 ⟺ $w=0$ ⟺ $u = \lambda v$ ⟺ **$u, v$ 가 일차종속**.

> 이 한 줄 증명이 위력적인 이유: 유클리드 벡터든, 함수든, 확률변수든, "내적"이라는 구조만 있으면 **공짜로** 부등식이 따라온다. Level 0~1은 이 일반정리의 특수경우일 뿐.

이 부등식이 곧 노름의 **삼각부등식**을 낳는다:
$\|u+v\|^2 = \|u\|^2 + 2\langle u,v\rangle + \|v\|^2 \le (\|u\|+\|v\|)^2$ → $\|u+v\|\le\|u\|+\|v\|$.

## 🟠 Level 3 — 해석·확률: 적분형과 상관계수

내적의 정의만 바꾸면 같은 부등식이 새 옷을 입는다.

**적분형 (함수의 내적 $\langle f,g\rangle=\int fg$):**
$$\left(\int_a^b f(x)g(x)\,dx\right)^2 \le \int_a^b f^2\,dx \cdot \int_a^b g^2\,dx$$

**확률형 (확률변수의 내적 $\langle X,Y\rangle = E[XY]$):**
$$\big(E[XY]\big)^2 \le E[X^2]\,E[Y^2]$$

$X,Y$ 를 평균중심화하면 ($X\to X-\mu_X$) 곧바로:

$$\big(\mathrm{Cov}(X,Y)\big)^2 \le \mathrm{Var}(X)\,\mathrm{Var}(Y) \;\Longrightarrow\; |\mathrm{corr}(X,Y)| \le 1$$

> **상관계수가 항상 $[-1,1]$ 안에 갇히는 근본 이유가 바로 코시-슈바르츠다.** [[표본상관계수(Pearson)]]의 $|r|\le1$ 도 같은 뿌리.

---

## 🔴 Level 4 — 교수 수준: 위치 짓기

1. **등호 조건의 통일된 진술**: 모든 레벨에서 등호 ⟺ $u,v$ 일차종속 (비례/평행/거의 확실히 상수배). 이는 잔차 $w$ 가 영벡터가 되는 사건.

2. **Hölder 부등식의 특수경우**: $\frac1p+\frac1q=1$ 일 때
$$\Big|\sum a_i b_i\Big| \le \Big(\sum|a_i|^p\Big)^{1/p}\Big(\sum|b_i|^q\Big)^{1/q}.$$
$p=q=2$ 가 정확히 코시-슈바르츠. 즉 CS는 Hölder의 "대칭 중심점".

3. **힐베르트 공간의 골격**: CS 부등식이 있어야 내적이 노름을 유도하고(삼각부등식), 노름이 거리를 유도해 완비성(Hilbert space)을 논할 수 있다. $L^2$ 공간, 푸리에 해석, 양자역학의 상태공간이 전부 이 위에 선다.

4. **사영정리와의 동치성**: Level 2의 $w=u-\text{proj}_v u$ 는 "최소제곱"의 원형이다. [[최소제곱추정량(LSE)]]이 $\hat y = Hy$ 로 $y$ 를 열공간에 **사영**하는 것과 정확히 같은 구조 — CS는 그 사영이 원본보다 길지 않음을 보장한다.

---

## 🔗 우리가 이걸 어디서 썼나 — [[Durbin-Watson 검정]]

$a_i = e_t,\ b_i = e_{t-1}$ 로 두면:

$$\Big(\sum_{t} e_t e_{t-1}\Big)^2 \le \Big(\sum e_t^2\Big)\Big(\sum e_{t-1}^2\Big)$$

분모 두 합이 모두 $\approx\sum e_t^2$ 이므로

$$|\hat\rho| = \frac{\big|\sum e_t e_{t-1}\big|}{\sum e_t^2} \le 1$$

→ 잔차 자기상관계수 $\hat\rho\in[-1,1]$, 따라서 $d\approx2(1-\hat\rho)\in[0,4]$. **DW 통계량이 0~4 사이에 갇히는 것이 코시-슈바르츠의 직접적 결과다.**

## 📖 교재 챕터 출처

**Hogg, *Introduction to Mathematical Statistics* 8th — §2.5 The Correlation Coefficient (p.125)** ⭐ 가장 정확한 출처 (PDF 본문 확인됨)
- **Thm 2.5.1**: $-1\le\rho\le1$. 증명이 $h(v)=E[(X-\mu_1)+v(Y-\mu_2)]^2\ge0$ 의 **판별식 $\le0$** 논법 → 본 노트 **Level 1 판별식 증명의 확률버전** (구조 동일).
- **Thm 2.5.2 + Ex 2.5.3**: 독립 ⇒ $\rho=0$, 단 역은 거짓 (상관 0이어도 독립 아님). → [[Durbin-Watson 검정]]의 "$\rho=0$ ⟺ 독립" 가정의 한계와 직결.

**김충락·강근석 『회귀분석』 2판** (※ 스캔 이미지본 — OCR 검증 결과 반영, 2026-06-28)
- **부록 A 행렬이론**: OCR로 전 페이지 확인 결과 섹션 구성은 A.1~A.5 (역행렬·일반화역행렬·계수·고유값·**이차형식**(A.5)). **내적/벡터노름 섹션이 없고, 코시-슈바르츠가 번호 붙은 정리로 실려 있지 않음.** → 앞서의 "부록 A가 CS의 본거지" 추정은 **오류였음**. 다만 A.5 이차형식·양의 정부호는 [[Gauss-Markov 정리]]가 쓰는 관련 토대.
- **제1장 기초통계이론**: 공분산·상관계수 $|\text{corr}|\le1$ 의 자연스러운 위치이나, **정확한 정리 번호는 미확인** — 스캔본이고 이 환경에서 한국어 OCR 언어팩 설치가 막혀 한글 정리 라벨("정리 1.x")을 읽지 못함. 라틴 표기 "Cauchy-Schwarz"도 추출 안 됨.
  - ✅ 채우는 법: 로컬에서 한국어 OCR(예: 1장에 `tesseract -l kor`) 돌리거나, 해당 페이지를 알려주면 번호 확정.
