# [[Breusch-Godfrey 검정]] — DW를 넘어서는 일반 자기상관 검정

> 한 줄: **"과거 잔차 $e_{t-1},\dots,e_{t-p}$ 가 현재 잔차 $e_t$ 를 설명하는가?"** 를 보조회귀의 $R^2$ 로 묻는 [[라그랑주 승수 검정(LM test)]]. $nR^2\sim\chi^2_p$.
---

## 1. 왜 BG인가 — [[Durbin-Watson 검정]]의 세 한계

DW는 정확한 $p$-값을 써도 못 고치는 **구조적** 약점이 있다:

1. **차수 1만 본다**: $d$ 는 $e_t$ 와 *바로 직전* $e_{t-1}$ 만 비교 → [[AR(1) 과정]]만 겨냥. 분기자료의 4차(계절) 자기상관 등 고차 구조를 놓침.
2. **시차종속변수에서 무효**: 회귀변수에 $y_{t-1}$ 이 있으면 $d$ 가 2 쪽으로 편향되어 검정력 상실.
3. **판정 불가능 구간**: 고전적 표 사용 시 $d_L\sim d_U$ 회색지대.

BG는 셋을 모두 해소한다.

---

## 2. 핵심 발상

자기상관이 있다 ⟺ 과거 잔차가 현재 잔차를 **예측**한다. 그러니 "예측력"을 측정해 검정으로 바꾼다.

---

## 3. 검정 절차 (보조회귀, auxiliary regression)

**Step 1.** 원모형 $y_t=x_t'\beta+\varepsilon_t$ 적합 → 잔차 $e_t$.

**Step 2.** 보조회귀: $e_t$ 를 **원래 설명변수 $x_t$ + 과거 잔차 $p$ 개**에 회귀.
$$e_t = x_t'\gamma + \alpha_1 e_{t-1}+\alpha_2 e_{t-2}+\dots+\alpha_p e_{t-p}+v_t$$
(결측 시차잔차 $e_0,e_{-1},\dots$ 는 0으로 채움 — 표준 구현.)

**Step 3.** 이 보조회귀의 결정계수 $R^2$ 로 검정통계량:
$$\boxed{\ LM = nR^2\ \xrightarrow{\ H_0\ }\ \chi^2_{(p)}\ }$$
$H_0:\alpha_1=\dots=\alpha_p=0$ (자기상관 없음). $LM$ 이 $\chi^2_{(p)}$ 임계값 초과 → 기각.

---

## 4. 왜 $nR^2\sim\chi^2_{(p)}$ 인가 ([[라그랑주 승수 검정(LM test)]] 구조)

- $H_0$ 하에서 과거 잔차는 $e_t$ 에 대해 **무력** → 보조회귀 $R^2\approx0$ → $nR^2$ 작음.
- 자기상관 존재 시 $R^2$ 상승 → $nR^2$ 커짐.
- 자유도 = **제약의 개수 $p$** ($\alpha_1,\dots,\alpha_p$ 를 0으로 두는 제약). 이것이 LM(점수) 검정의 전형: "제약 모형의 잔차가 제약을 풀면 얼마나 설명되는가"를 $nR^2$ 로 측정, 점근적으로 $\chi^2_{(\text{제약수})}$.

---

## 5. 왜 보조회귀에 원래 $X$ 를 넣는가 (DW가 무너지는 곳에서 BG가 사는 이유)

잔차는 설계상 $X$ 와 직교($X'e=0$)지만, 보조회귀에 $X$ 를 **함께** 넣어야 시차종속변수($y_{t-1}$ 등)가 회귀변수에 있을 때도 검정이 **유효**하게 유지된다. DW(및 Durbin's $h$)가 이 상황에서 편향되는 것과 대조되는 BG의 결정적 장점.

---

## 6. DW vs BG 비교

| | [[Durbin-Watson 검정]] | [[Breusch-Godfrey 검정]] |
|---|---|---|
| 대립가설 | AR(1)만 | AR(p)/MA(q), 임의 차수 $p$ |
| 분포 | 이차형식 비 ($X$-의존, 정확분포 필요) | $nR^2\sim\chi^2_p$ (점근) |
| 판정 불가능 구간 | 있음(고전표) | 없음 |
| 시차종속변수 | 무효(편향) | 유효 |
| 표본 크기 | 소표본도 정확$p$ 가능 | **대표본**에서 신뢰 (점근검정) |

> 맞교환: BG는 유연하지만 **점근**검정이라 소표본에서 근사가 거침. 순수 AR(1)·소표본이면 정확 $p$-값의 DW가 더 낫다.

---

## 7. 계산 예시 (기본 R) — 차수를 바꿔가며

DW 예시와 **동일한 고정 데이터**. (숫자는 동등 계산으로 검증함.)

```r
x <- 1:12
y <- c(3.1, 3.0, 3.2, 4.0, 5.3, 6.9, 8.1, 8.0, 7.7, 8.2, 9.6, 11.5)
fit <- lm(y ~ x)

library(lmtest)
bgtest(fit, order = 1)   #> LM = 2.180,  df = 1,  p-value = 0.1398
bgtest(fit, order = 2)   #> LM = 9.068,  df = 2,  p-value = 0.0107
bgtest(fit, order = 4)   #> LM = 10.159, df = 4,  p-value = 0.0378
```

| order $p$ | $R^2$ | $LM=nR^2$ | $\chi^2_p$ $p$-값 | 판정 |
|---|---|---|---|---|
| 1 | 0.182 | 2.18 | 0.140 | 비기각 |
| 2 | 0.756 | 9.07 | 0.011 | **기각** |
| 4 | 0.847 | 10.16 | 0.038 | **기각** |

**읽는 점**: $p=1$ 만 보면 자기상관을 못 잡지만, $p=2$ 로 올리면 또렷이 잡힌다 — 이 데이터엔 **2차 구조**가 있다는 뜻. DW(차수1 고정)가 놓칠 수 있는 걸 BG가 차수를 키워 잡아내는 장면. (단 $n=12$ 소표본이라 점근 $p$-값은 참고용; 같은 데이터에서 정확 DW는 $p=0.0101$ 로 더 신뢰.)
