# [[Durbin-Watson 검정]] — 오차항 독립성 진단

> Ch4 잔차가정 3축: ① 정규성 ✅ → ② [[등분산성(homoscedasticity)]] ✅ → ③ **독립성(이 노트)** ✅

---

## ⚠️ 내가 자꾸 틀리는 부분 (2026-06-28 세션 기록)

> 다음에 이 유도를 다시 할 때, **여기부터 읽고 시작할 것.** 네 번 미끄러진 지점이다.

1. **$\rho$ 를 "회귀계수"라고 부름 ❌**
   → $\rho$ 는 모형의 $\beta$ 가 아니라 오차항 [[AR(1) 과정]] $\varepsilon_t = \rho\varepsilon_{t-1}+u_t$ 의 **1차 자기상관계수**다. ($\varepsilon_{t-1}$ 에 회귀시킨 계수라 직관은 비슷하지만 이름이 다르다.)

2. **분모를 "제곱합의 *평균*"이라고 함 ❌**
   → 분모는 그냥 **합** $\sum e_t^2$ 이다. 분자도 합($\sum(e_t-e_{t-1})^2$)이라서, 분모를 $n$ 으로 나누면 약분 안 된 $n$ 이 통계량에 덜렁 남는다. **분자가 합이면 분모도 합.**

3. **마지막 정리에서 계수 2를 빠뜨림 ❌ (가장 잦은 실수)**
   → $\dfrac{2(A-B)}{A} = 2 - \dfrac{\mathbf{2}B}{A}$. 둘째 항의 **2를 절대 떨어뜨리지 말 것.** 이걸 빠뜨리면 $d \approx 2(1-\hat\rho)$ 가 아니라 엉뚱한 $2(1-\tfrac12\hat\rho)$ 가 된다.

4. **$\sqrt{A^2}=A$ 를 "분산"이라고 부름 ❌**
   → $\sqrt{A^2}=A=\sum e_t^2$ 은 **잔차 제곱합(SSE)**이다. 분산이 아니다.
   - 잔차 제곱합: $\sum e_t^2$ (그냥 합)
   - 잔차 분산: $\dfrac{1}{n-p}\sum e_t^2$ (자유도로 **나눈** 것)
   - DW에서 쓰는 건 **나누지 않은 날것의 합**.

---

## 1. 무엇을 검정하나 — 가설 설정

독립성이 깨지는 가장 단순한 구조를 가정한다: 오차항이 1차 자기회귀 [[AR(1) 과정]]을 따른다.

$$\varepsilon_t = \rho\,\varepsilon_{t-1} + u_t, \qquad u_t \overset{iid}{\sim} N(0,\sigma_u^2)$$

이때 "독립이다"는 $\rho=0$ 이라는 점가설로 번역된다.

$$H_0:\ \rho = 0 \quad(\text{자기상관 없음, 독립})\qquad\text{vs}\qquad H_1:\ \rho \neq 0$$

- 실무에서는 흔히 단측 $H_1:\rho>0$ (양의 자기상관)을 본다. 시계열에서 인접 오차가 같은 부호로 끌려가는 경우가 압도적으로 흔하기 때문. 이 비대칭성이 나중에 판정표의 **판정 불가능 구간**으로 이어진다.

---

## 2. 왜 잔차로 검정하나 — 참 오차는 관측 불가

$$\varepsilon_t = Y_t - (\beta_0+\beta_1 x_t) = Y_t - E[Y_t\mid x_t]$$

참 오차는 **참 모수 $\beta$ 에 의존**하는데, $\beta$ 의 참값은 영원히 모른다 → $\varepsilon_t$ 계산 불가.
대신 [[최소제곱추정량(LSE)]] $\hat\beta$ 로 그린 직선에서의 이탈, 즉 **잔차**를 쓴다.

$$e_t = Y_t - \hat Y_t = Y_t - (\hat\beta_0+\hat\beta_1 x_t), \qquad \mathbf{e}=(I-H)\mathbf{Y}$$

잔차 $e_t$ 는 관측 가능한 $\varepsilon_t$ 의 proxy. (단 $\mathbf e=(I-H)\mathbf Y$ 라 [[Hat Matrix의 멱등성 및 대칭성|투영행렬]]을 거치며 약하게 엮인다 → 정확분포가 지저분해지는 근원.)

---

## 3. 통계량의 구성 (직관 → 식)

- $\rho>0$ 이면 인접 잔차가 닮음 → 차이 $(e_t-e_{t-1})$ 가 **작다**.
- 부호 상쇄를 막으려 **제곱**해서 더한다 → 분자.
- 단위(척도)에 휘둘리지 않도록 같은 척도로 커지는 양으로 나눈다 → 분모 $\sum e_t^2$.

$$\boxed{\,d = \dfrac{\sum_{t=2}^{n}(e_t-e_{t-1})^2}{\sum_{t=1}^{n} e_t^2}\,}$$

---

## 4. 핵심 근사 $d \approx 2(1-\hat\rho)$ 유도

분자 전개:

$$\sum_{t=2}^n (e_t-e_{t-1})^2 = \sum_{t=2}^n e_t^2 - 2\sum_{t=2}^n e_t e_{t-1} + \sum_{t=2}^n e_{t-1}^2$$

큰 $n$ 에서 양 끝 한 항만 차이 나므로 ($\frac{\text{끝항}}{\text{전체합}}=O(1/n)\to0$, 점근적 무시 — 표기 정의는 [[점근 표기법(Big-O)]], 근거는 [[대수의 법칙(LLN)]]):

$$\sum_{t=2}^n e_t^2 \approx \sum_{t=2}^n e_{t-1}^2 \approx \sum_{t=1}^n e_t^2 \equiv A$$

따라서

$$\sum_{t=2}^n (e_t-e_{t-1})^2 \approx 2A - 2\sum e_t e_{t-1}$$

$$d \approx \frac{2A - 2\sum e_t e_{t-1}}{A} = 2\left(1 - \frac{\sum e_t e_{t-1}}{\sum e_t^2}\right) = \boxed{2(1-\hat\rho)}$$

> ⚠️ 위 3번 실수 주의: $\dfrac{2(A-B)}{A}=2-\dfrac{2B}{A}$. 계수 2 살릴 것.

---

## 5. 왜 $\hat\rho$ 가 "상관계수"인가 (건너뛰기 쉬운 다리)

일반 [[표본상관계수(Pearson)]] 정의에 $(X,Y)=(e_t,\,e_{t-1})$ 를 대입:

$$\hat\rho = \frac{\sum (e_t-\bar e)(e_{t-1}-\bar e)}{\sqrt{\sum(e_t-\bar e)^2\cdot\sum(e_{t-1}-\bar e)^2}}$$

**단순화 ①** 절편 모형의 [[정규방정식]] $X^\top e=0$ 의 첫 줄 → $\sum e_t = 0$ → $\bar e = 0$ → 중심화 항 소거 → 분자 $=\sum e_t e_{t-1}$.

**단순화 ②** 분모 두 합 모두 $\approx A$ → $\sqrt{A\cdot A}=\sqrt{A^2}=A=\sum e_t^2$.

$$\therefore\ \hat\rho = \frac{\sum_{t=2}^n e_t e_{t-1}}{\sum_{t=1}^n e_t^2} \quad(\text{잔차의 표본 1차 자기상관계수})$$

- $\hat\rho\in[-1,1]$ 인 이유: 분자 $\le$ 분모를 보장하는 [[코시-슈바르츠 부등식]] $\left|\sum e_t e_{t-1}\right|\le\sqrt{\sum e_t^2}\sqrt{\sum e_{t-1}^2}$.

---

## 6. 해석 — $d$ 의 범위와 판정

$\hat\rho\in[-1,1]$ 을 $d\approx2(1-\hat\rho)$ 에 대입:

| $\hat\rho$ | $d$ | 의미 |
|---|---|---|
| $0$ | $\approx 2$ | 자기상관 없음 → **독립 OK** |
| $\to +1$ | $\to 0$ | 강한 양의 자기상관 |
| $\to -1$ | $\to 4$ | 강한 음의 자기상관 |

→ $d\in[0,4]$, **$d\approx2$ 가 안심 기준**. 0에 가까우면 양, 4에 가까우면 음의 자기상관.

---

## 7. 판정 구간과 판정 불가능(inconclusive) — 그리고 대칭성

### 7.1 왜 임계값이 점이 아니라 두 값 $d_L, d_U$ 인가
$t$·$F$ 통계량은 귀무분포가 $X$ 와 무관한 표준분포라 임계값이 **하나**다. 그러나 $d$ 는 잔차 $\mathbf e=(I-H)\mathbf Y$ 로 만들어지고, $H=X(X'X)^{-1}X'$ 는 **설명변수 $X$ 로만 결정**된다. 따라서 $d$ 의 귀무분포가 **$X$ 에 의존** → 데이터셋마다 진짜 임계값 $c$ 가 떠다님 → 단일 임계표 불가.

Durbin–Watson의 우회: $X$ 가 무엇이든 진짜 임계값이 항상
$$d_L \le c \le d_U$$
사이에 갇힘을 증명. **$d_L, d_U$ 는 $X$ 와 무관**하고 오직 $(n, k)$ 에만 의존 → 표로 작성 가능.

### 7.2 판정 규칙 (양의 자기상관, 단측 $H_1:\rho>0$)

```
0 ───┬───── d_L ──┬── d_U ───┬─── 2 ───┬── (4-d_U) ──┬── (4-d_L) ──┬─── 4
     │   기각      │ 판정불가  │   채택 (자기상관 없음)  │  판정불가   │   기각      │
     │ (양의 자기상관)│         │      ← d≈2 안전지대 →   │            │ (음의 자기상관)│
```

| 구간 | 논리 | 판정 |
|---|---|---|
| $d < d_L$ | $d<d_L\le c$ → $d<c$ ($X$ 무관 보장) | $H_0$ **기각** (양의 자기상관) |
| $d_L\le d\le d_U$ | $d$ 와 $c$ 둘 다 이 띠 안, $c$ 위치 미상 → 대소 단정 불가 | **판정 불가능** |
| $d>d_U$ | $c\le d_U<d$ → $d>c$ | $H_0$ **채택** (독립 OK) |

> **판정 불가능의 정체**: $d$ 가 판정 불능인 게 아니라, $X$-의존성을 버린 보수적 경계라서 표에 **$c$ 의 정확한 위치 정보가 없다.** 그래서 검정이 침묵.

### 7.3 음의 자기상관 — 대칭성으로 처리
$d$ 는 2를 중심으로 대칭($\hat\rho\leftrightarrow-\hat\rho$). 따라서 **음의 자기상관 검정 = $4-d$ 로 하는 양의 자기상관 검정**. 같은 표의 $d_L, d_U$ 에 $4-d$ 를 넣는다:
$$4-d < d_L \iff d > 4-d_L \quad(\text{음의 자기상관 기각})$$
$$4-d_U \le d \le 4-d_L \quad(\text{음의 쪽 판정 불가능})$$
→ 표가 $d_L, d_U$ **두 값만** 싣고도 양·음 양쪽을 처리하는 비결.

## 8. 왜 $p$-값이 존재하나 — $d$ 의 표집분포

$p$-값이 있다는 건 $d$ 가 $H_0$ 하에서 **분포**를 갖는다는 뜻. 그 분포의 정체:

**(1) 무엇이 랜덤인가**: $H_0$ 하 $\boldsymbol\varepsilon\sim N(0,\sigma^2 I)$ → $\mathbf e=(I-H)\boldsymbol\varepsilon$ → $d$ 가 표본마다 변동. 이 변동의 분포가 표집분포, 그 꼬리 넓이가 $p$-값.

**(2) $d$ 는 이차형식의 비**: $M=I-H$ 로 두면
$$d=\frac{\mathbf e'A\mathbf e}{\mathbf e'\mathbf e}=\frac{\boldsymbol\varepsilon'MAM\boldsymbol\varepsilon}{\boldsymbol\varepsilon'M\boldsymbol\varepsilon}\quad(A=\text{1차 차분 삼중대각 행렬})$$
같은 정규벡터 $\boldsymbol\varepsilon$ 에 대한 두 이차형식의 비.

**(3) 왜 $\chi^2$·$F$ 가 아닌가**: 분모 $\boldsymbol\varepsilon'M\boldsymbol\varepsilon$ 은 $M$ 멱등이라 $\sigma^2\chi^2_{n-p}$ ([[이차형식과 Cochran 정리]], [[Hat Matrix의 멱등성 및 대칭성]]). 그러나 $F$ 가 되려면 분자·분모가 **각각 $\chi^2$ + 서로 독립**이어야 하는데, $MAM$ 은 멱등 아님($A\neq cI$) + 분자·분모가 같은 $\boldsymbol\varepsilon$ 공유로 독립 아님 → 둘 다 깨짐. 그래서 이름 없는 **"이차형식 비"의 분포** (자유도 미분할이라 엄밀히는 베타족; $F$ 는 그 단조변환).

**(4) 고유값으로 계산 ([[Imhof 방법]])**: 비를 부등식으로 전환 —
$$P(d\le d_0)=P\big(\boldsymbol\varepsilon'\underbrace{M(A-d_0 I)M}_{B}\boldsymbol\varepsilon\le 0\big),\qquad \boldsymbol\varepsilon'B\boldsymbol\varepsilon=\sum_j\lambda_j Z_j^2$$
부호 섞인 가중 $\chi^2_1$ 합이 음수일 확률. 닫힌형 없음 → 특성함수를 수치적분으로 역변환(Imhof 1961). **1950년에 불가능, 컴퓨터로 가능.**

**(5) 다시 원점**: 고유값 $\lambda_j$ 가 $B=M(A-d_0I)M$, 즉 $M=I-H$ 통해 **$X$ 에 의존** → 분포가 데이터셋마다 다름 → §7 판정 불가능 구간의 근원.

> **핵심 한 줄**: 분모는 잔차를 *하나씩 따로* 봐서 깔끔한 $\chi^2$, 분자는 잔차를 ***이웃끼리 엮어*** 봐서 $X$-의존 복잡분포. 그 "이웃 엮기"는 약점이 아니라 자기상관을 잡는 DW의 **존재 이유**. (맞교환: 이웃을 감지하려면 분포의 깔끔함을 포기해야 한다.)

## 9. 계산 예시 (기본 R) — 표는 침묵, 컴퓨터는 판정

```r
# --- 데이터 (고정값, 재현 가능): t=1..12, 추세 위 양의 자기상관 오차 ---
x <- 1:12
y <- c(3.1, 3.0, 3.2, 4.0, 5.3, 6.9, 8.1, 8.0, 7.7, 8.2, 9.6, 11.5)

# --- 1) OLS 적합 후 잔차 ---
fit <- lm(y ~ x); e <- resid(fit)

# --- 2) DW 통계량: 유도한 공식 그대로 (기본 R 한 줄) ---
d <- sum(diff(e)^2) / sum(e^2)        #> 1.0226   (diff(e) = e_t - e_{t-1})

# (검산) rho_hat 과 근사식 d ≈ 2(1-rho_hat)
rho <- sum(e[-1]*e[-length(e)]) / sum(e^2)
c(rho_hat = rho, approx = 2*(1-rho))  #> rho_hat=0.3901, approx=1.2198

# --- 3) 정확한 p-값: 실제 X로 계산 (lmtest가 Imhof 적분 수행) ---
library(lmtest)
dwtest(fit, alternative = "greater")  #> DW=1.0226, p-value=0.0101
```

**핵심**: 잔차 부호가 `+ − − − − + + + − − − +` 로 뭉쳐 양의 자기상관이 보임 → $d=1.02<2$.
1950년대 표(n=12,k=1,α=.05: $d_L\approx0.97,\,d_U\approx1.33$)로는 $d=1.02\in[0.97,1.33]$ → **판정 불가능**.
그러나 실제 $X$ 로 계산한 정확한 $p=0.0101<0.05$ → **기각**. 표가 못 가린 걸 컴퓨터가 가린다 = §8·탈출구의 실전 가치.
