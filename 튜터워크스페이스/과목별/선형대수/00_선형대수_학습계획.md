## 📗 W2. 열공간·직교·투영 — Cluster E (B 교차)

**목표**: 최소제곱을 "$y$를 $X$의 열공간으로 정사영"으로 이해하고, Hat Matrix $H=X(X^\top X)^{-1}X^\top$ 와 잔차 직교성 $X^\top e=0$ 을 유도한다.

- [ ] [4-3강. 최소자승법 3 문제](https://www.youtube.com/watch?v=g-3B8b-8u5Q)
- [ ] [9-1강. 그람-슈미트 직교화](https://www.youtube.com/watch?v=D7koMV2AeLE)
- [ ] [9-2강. QR 분해](https://www.youtube.com/watch?v=KxAX_evOMtw)

**핵심 질문 (소크라테스식)**
1. $\hat y$ 는 왜 $X$의 열공간 안에 있어야 하고, 잔차 $e$는 왜 그 공간과 수직이어야 "최소"가 되는가?
2. $H$를 두 번 곱해도 같은 결과($H^2=H$)가 나오는 것을 기하적으로 설명하면?
3. $X=QR$ 로 쓰면 정규방정식은 어떤 모양이 되는가? 왜 수치적으로 더 안정적인가?

**R 확인 과제**
- [ ] 작은 $X$로 `H <- X %*% solve(t(X)%*%X) %*% t(X)` → `H %*% H` 와 `H` 비교, `t(X) %*% (y - H%*%y)` ≈ 0 확인
- [ ] `qr.Q()`, `qr.R()` 로 $\hat\beta = R^{-1}Q^\top y$ 계산 → `lm()` 과 비교

**기출 연결**
- [ ] 회귀진단 잔차 그림 가로축이 $\hat y$ 인 이유를 투영으로 재설명 (기존 노트와 연결)
- [ ] 36-3 잔차 진단 시 $\hat y^\top e=0$ 을 수치로 확인

## 📗 W3. 고유값·대칭·멱등행렬 — Cluster B (현재 다음 초점)

**목표**: 대칭 멱등행렬의 고유값이 0 또는 1뿐이고 $\mathrm{rank}=\mathrm{tr}$ 임을 보이고, 이것이 이차형식 $y^\top Ay\sim\chi^2(\mathrm{rank}\,A)$ 와 SS 분해·자유도로 이어지는 흐름을 잡는다.

> ⚠️ 멱등행렬은 재생목록에 별도 강의가 없음 → **Hogg 8판 (이차형식 부분)·김충락 회귀분석 노트(Hat Matrix·이차형식)** 로 보충.

**핵심 질문 (소크라테스식)**
1. $A^2=A$ 이면 고유값 $\lambda$ 는 어떤 방정식을 만족하는가? 가능한 값은?
2. 대칭 멱등행렬에서 $\mathrm{tr}(A)$ 가 왜 랭크와 같아지는가? $\mathrm{tr}(H)$ 와 $\mathrm{tr}(I-H)$ 는 각각 무엇을 세는가?
3. $SST=SSR+SSE$ 에서 세 행렬은 어떤 관계(합·곱)를 가져야 각 SS가 독립인 $\chi^2$ 가 되는가?

**R 확인 과제**

## 📗 W6. 조건수·$X^\top X+\lambda I$ — Cluster A

**목표**: 조건수로 공선성을 수치적으로 진단하고, Ridge 해 $(X^\top X+\lambda I)^{-1}X^\top y$ 가 고유값을 $\lambda$ 만큼 들어 올려 안정화한다는 것, 그리고 표준화가 필요한 이유를 설명한다.

**영상**
- [ ] [6-4강. 의사역행렬](https://www.youtube.com/watch?v=14oiGnaMoNo)

> ⚠️ Ridge는 재생목록에 없음 → **ESL Ch3 (Ridge·SVD 관점)** 으로 보충.

**핵심 질문 (소크라테스식)**
1. $X^\top X$ 의 고유값이 $d_j^2$ 일 때 $X^\top X+\lambda I$ 의 고유값은? 가장 작은 고유값이 0에 가까울 때 무엇이 달라지는가?
2. SVD로 쓰면 Ridge는 각 주성분 방향을 어떤 비율로 줄이는가? 의사역행렬과는 어떻게 다른가?
