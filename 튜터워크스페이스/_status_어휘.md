# status 어휘

학습 노트의 `status`는 아래 여섯 값만 쓴다. 한 번에 하나.

```
stub → 초안 → 진행중 → 백지유도 통과 → 정착
                                    └→ 재발
```

| 값 | 의미 |
|----|------|
| `stub` | 링크·골격만 있다. 백지유도 전. |
| `초안` | 본문이 있다. 학습자 백지유도는 아직이다. 튜터가 써 둔 노트도 여기다. |
| `진행중` | 백지유도 세션이 열려 있다. |
| `백지유도 통과` | 학습자가 그 유도를 한 번 통과했다. 후속 과제가 남아 있을 수 있다. |
| `정착` | 통과한 내용이 정리되어 다음 주제로 넘어갔다. |
| `재발` | 한 번 통과하거나 정착한 뒤, 다시 유도가 흔들렸다. |

단계 밖의 설명은 `status`에 붙이지 않는다. `status_note`에 둔다.

노트 종류가 학습 단계와 다르면 `kind`를 쓴다. `kind`가 있으면 `status`는 비울 수 있다.

| kind | 의미 |
|------|------|
| `예시` | 빈 템플릿. 실제 공부 노트로 교체할 파일. |
| `참조` | 번역·외부 자료. 백지유도 대상이 아니다. |
| `도구` | 여러 과목이 쓰는 수학 도구. |
| `사다리` | 수준을 쌓아 올린 설명 노트. |
| `연계풀이` | 기출 풀이와 개념 노트를 묶은 정리. |

Codex 검토보고서의 `pass` / `issues_found` / `blocked`는 이 어휘가 아니다.

과거 세션의 「이어가기」 문장에 남은 `완료` 같은 말은 당시 기록이라 고치지 않는다.
