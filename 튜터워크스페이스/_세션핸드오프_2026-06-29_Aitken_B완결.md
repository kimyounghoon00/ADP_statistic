## 3. 핵심 결과 · 도달 상태 (State) ⭐
- 분해 항등식: $\text{Var}(\tilde\beta)=\text{Var}(\hat\beta_{GLS})+\sigma^2 DVD'$ ($D:=C-C_{GLS}$).
- 교차항 소거 열쇠: 불편성 → $DX=0$, 그리고 $C_{GLS}V=(X'V^{-1}X)^{-1}X'$ → $C_{GLS}VD'=(X'V^{-1}X)^{-1}(DX)'=0$.
- 첫 항 = $\text{Var}(\hat\beta_{GLS})$: $X'C_{GLS}'=(C_{GLS}X)'=I_p$.
- 결론: $\sigma^2 DVD'\succeq0$ (V 양정치) → $\text{Var}(\tilde\beta)\succeq\text{Var}(\hat\beta_{GLS})$. 등호 $\iff D=0\iff C=C_{GLS}$ → **유일 BLUE**. ∎

## 4. 막힌 지점 / 교정한 실수 (Stuck→Fixed)
- $C=X^{-1}$ 로 적음 → $X$ 가 $n\times p$ 비정사각이라 양쪽 역행렬 없음. $CX=I_p$ 는 **왼쪽 역행렬**이며 무수히 많다(=경쟁자 집합 $\mathcal C$). → `[[행렬 곱의 계수 부등식]]`
- "$V$ 양정치" 가정의 쓰임을 질문 → 명제 가정 ③에서 ($V^{-1}$ 존재 + $\mathbf w'V\mathbf w\ge0$) 두 역할 확인.
