### (c) $\text{Var}(\hat{\beta}_1) = \dfrac{\sigma^2}{S_{XX}}$ 유도

$\hat{\beta}_1 = \sum_{i=1}^n w_i y_i$, 단 $w_i = \dfrac{x_i - \bar{x}}{S_{XX}}$

$y_i$들이 서로 독립이고 $\text{Var}(y_i) = \sigma^2$이므로:

$$\text{Var}(\hat{\beta}_1) = \sum_{i=1}^n w_i^2 \text{Var}(y_i) = \sigma^2 \sum_{i=1}^n w_i^2$$

$$\sum_{i=1}^n w_i^2 = \sum_{i=1}^n \frac{(x_i-\bar{x})^2}{S_{XX}^2} = \frac{S_{XX}}{S_{XX}^2} = \frac{1}{S_{XX}}$$

$$\therefore \text{Var}(\hat{\beta}_1) = \frac{\sigma^2}{S_{XX}}$$

---

### (d) $\text{Var}(\hat{\beta}_0) = \sigma^2\!\left(\dfrac{1}{n} + \dfrac{\bar{x}^2}{S_{XX}}\right)$ 유도

$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} = \sum_{i=1}^n w_i^* y_i$, 단 $w_i^* = \dfrac{1}{n} - \dfrac{\bar{x}(x_i-\bar{x})}{S_{XX}}$

$y_i$들이 서로 독립이므로:

$$\text{Var}(\hat{\beta}_0) = \sigma^2 \sum_{i=1}^n {w_i^*}^2$$

$\sum {w_i^*}^2$ 계산 — $(a-b)^2$ 전개:

$$\sum \left(\frac{1}{n} - \frac{\bar{x}(x_i-\bar{x})}{S_{XX}}\right)^2 = \frac{n}{n^2} - \frac{2\bar{x}}{nS_{XX}}\underbrace{\sum(x_i-\bar{x})}_{=0} + \frac{\bar{x}^2}{S_{XX}^2}\underbrace{\sum(x_i-\bar{x})^2}_{=S_{XX}}$$

> ⚠️ **교차항의 계수 2** (2026-08-21 무결성 검토 F-09에서 교정): $(a-b)^2=a^2-\mathbf{2}ab+b^2$ 이므로 가운데 항은 $-\dfrac{2\bar x}{nS_{XX}}\sum(x_i-\bar x)$ 다.
> 여기서는 $\sum(x_i-\bar x)=0$ 이라 **최종 결과는 영향받지 않지만**, 같은 유형의 실수가 `[[Durbin-Watson 검정]]` §4에서도 "가장 잦은 실수"로 기록돼 있다($d=2-\frac{\mathbf{2}B}{A}$). 전개할 때 교차항 계수를 먼저 적는 습관을 들일 것.

$$= \frac{1}{n} + \frac{\bar{x}^2}{S_{XX}}$$

$$\therefore \text{Var}(\hat{\beta}_0) = \sigma^2\!\left(\frac{1}{n} + \frac{\bar{x}^2}{S_{XX}}\right)$$

## 2. 자주 누락하는 가정 또는 주의할 포인트

* **$x_i$의 비확률성**: $x_i$는 연구자가 미리 고정한 상수(non-stochastic). 따라서 $w_i$, $w_i^*$, $\bar{x}$, $S_{XX}$ 모두 상수. 이것이 $\text{Var}(w_i y_i) = w_i^2\sigma^2$ 계산의 전제.
  - 실험연구(온도, 용량 지정): 자연스럽게 성립
  - 관측연구(키, 몸무게): $x_i$가 원래 확률변수지만 조건부 기댓값 $E(\cdot \mid x_1,\ldots,x_n)$으로 처리
* **독립성**: $\text{Cov}(y_i, y_j) = 0$ ($i \neq j$) — $\text{Var}(\sum w_i y_i) = \sum w_i^2\text{Var}(y_i)$의 근거
* **등분산성**: $\text{Var}(y_i) = \sigma^2$ (모든 $i$에 동일)
* **$S_{XX} \neq 0$**: 모든 $x_i$가 동일한 값이면 $S_{XX}=0$이 되어 $w_i$ 정의 불가 → 회귀분석 자체가 불가능
