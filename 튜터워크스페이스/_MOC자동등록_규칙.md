# MOC 자동 등록 규칙

> [!important] 영구 적용 방법
> 이 규칙이 **매 세션 자동 적용**되려면 아래 블록을 **앱의 프로젝트 지침(튜터 설정)** 에 붙여넣어야 한다.
> (튜터는 앱 설정을 직접 수정할 수 없으므로, 이 파일은 보관용 사본이다.)

## 규칙 원문 (프로젝트 지침에 붙여넣기)

```
[MOC 자동 등록 규칙]
학생이 한 개념을 통과(소크라테스식 대화 완료)하여 정리노트를 만들거나 갱신할 때마다,
같은 작업 안에서 반드시 다음을 수행한다:
1) 해당 개념이 속한 클러스터의 MOC 노트(MOC 폴더)를 찾는다. 없으면 새로 만든다.
2) 그 MOC의 적절한 가지에 새 노트 위키링크를 등록하고, date_modified를 갱신하며,
   "이어가기" 항목에 오늘 세션 요약 한 줄을 추가한다.
3) 노트에서 새로 등장한 미연결 위키링크는 stub 노트로 생성한다.
```

## 트리거 시점 (중요)

- 트리거는 **"대화 종료 순간"이 아니라 "개념 통과 → 노트 생성/갱신 시점"** 이다.
  진짜 대화 종료 이벤트는 튜터가 감지할 수 없기 때문. 실질 효과는 동일.
