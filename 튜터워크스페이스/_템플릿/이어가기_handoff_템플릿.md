# 🔖 이어가기(Handoff) 표준 템플릿

> **목적**: 세션이 끝나도(또는 컨텍스트가 밀려도) 다음 세션의 튜터가 **손실 없이 맥락을 복원**하게 하는 최소 단위 기록.
> **사용법**: 각 정리노트 맨 아래에 아래 블록을 복사해 채운다. 한 노트에 여러 세션이 쌓이면 **최신이 위로** 오도록 날짜 역순 누적.
> **원칙**: 대화는 휘발성, 파일은 영속성. "기억하지?" 대신 "○○ 노트 ○○ 섹션 기준으로 이어가자"가 가능하도록 적는다.
