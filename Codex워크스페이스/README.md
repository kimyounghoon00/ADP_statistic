# Codex 보조 워크스페이스

## 목적

이 폴더는 LLM Wiki의 주 작성자인 Claude Code와 역할을 겹치지 않게 하기 위한 Codex 전용 작업 공간이다. Codex는 아래 다섯 역할만 수행한다.

| 역할 | 수행 범위 | 기본 산출물 |
|---|---|---|
| QA 검토 | 노트 구조·내용의 누락, 모순, 탐색성 점검 | 검토보고서 |
| 자동화 | 반복 검증·정리 작업을 위한 도구 구현 | `scripts/`의 도구와 사용법 |
| 무결성 점검 | 위키링크, 제목·별칭, 메타데이터, 중복 후보 확인 | 무결성 보고서 |
| 독립 교차검증 | 통계 서술, 수식 유도, 코드·계산의 재검산 | 검증 메모 |
| 이슈 수정 | Claude 또는 사용자가 명시한 재현 가능한 이슈만 수정 | 최소 수정과 검증 결과 |

## 하지 않는 일

- 학습 세션을 주도하거나 소크라테스식 튜터 역할을 하지 않는다.
- 연습문제를 채점하거나 진도 대시보드를 일상적으로 운영하지 않는다.
- 요청 없이 기존 정리노트를 대량 작성·재구성·문체 교정하지 않는다.
- 검사 결과를 근거 없이 자동 수정하지 않는다.

## 표준 작업 흐름

1. 요청 범위와 대상 경로를 확인한다.
2. 먼저 읽기 전용 검사 또는 독립 검토를 한다.
3. 심각도(P0~P3), 근거, 영향 범위, 권장 조치를 갖춘 보고서를 남긴다.
4. 수정이 요청되면 가장 작은 변경으로 해결하고, 관련 검사만 다시 실행한다.

보고서는 `검토보고서/YYYY-MM-DD_범위_유형.md` 형식으로 만든다. 검토 기준과 보고서 양식은 [QA_체크리스트.md](QA_체크리스트.md)에 있다.

## 무결성 검사기

PowerShell에서 다음 명령을 실행한다.

```powershell
& .\Codex워크스페이스\scripts\Test-WikiIntegrity.ps1
```

메타데이터까지 점검하거나 Markdown 보고서를 저장할 때는 다음과 같이 사용한다.

```powershell
& .\Codex워크스페이스\scripts\Test-WikiIntegrity.ps1 -CheckMetadata -ReportPath .\Codex워크스페이스\검토보고서\YYYY-MM-DD_전체_무결성.md
```

기본 출력은 처음 30건만 보여 준다. 전체 목록이 필요하면 `-MaxIssues 10000`을 추가한다. 기본 모드는 파일을 변경하지 않는다. 보고서 파일은 `-ReportPath`를 지정한 경우에만 생성·갱신한다.
