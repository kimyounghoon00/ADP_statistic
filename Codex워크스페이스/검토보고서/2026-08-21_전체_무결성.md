2. **히스토리 재작성**: 백업 후 `git-filter-repo`로 대상 객체를 제거한다.
   ```bash
   git clone --mirror https://github.com/kimyounghoon00/ADP_statistic.git backup-$(date +%F).git
   pip install git-filter-repo
   git filter-repo --invert-paths \
       --path-glob '*.pdf' --path-glob '*.jpg' --path-glob '*.jpeg' \
       --path '튜터워크스페이스/regression_김충락/회귀분석_chapters'
   git push --force --all && git push --force --tags
   ```

3. **GitHub 캐시 정리 요청**: force-push 후에도 unreachable 객체는 SHA를 알면 한동안 접근된다. GitHub Support에 삭제(가비지 컬렉션)를 요청한다. 포크가 있다면 포크에도 남는다.
4. **재발 방지**: `.gitignore`는 이미 적절하다(`*.pdf`, `*.jpg`, OCR 전사본, 번역본). 여기에 pre-commit 훅으로 `*.pdf|*.jpg` 스테이징을 차단하면 완전해진다.

> **참고 — 정책 경계는 지켜지고 있다.** `.gitignore`의 저작권 정책 자체는 잘 설계돼 있고, 워킹트리에는 위반이 없다(`git check-ignore` 전수 검사에서 "무시 대상인데 추적 중"인 파일 0건). `[[Montgomery 불균형·공변량 ANOVA와 Type I·II·III]]`에 있는 Montgomery 원문 2문장은 **쪽수를 명시한 짧은 인용**이라 학술적 인용 범위이며 문제 없다.

### 🟡 P3 — 사소하지만 고쳐두면 좋은 것

#### F-09. `08_정리노트.md:40` — $(a-b)^2$ 전개에서 계수 2 누락

```
현재:  Σ(1/n − x̄(xᵢ−x̄)/S_XX)² = n/n² − (x̄/(nS_XX))·Σ(xᵢ−x̄) + (x̄²/S_XX²)·Σ(xᵢ−x̄)²
정정:                              …  − (2x̄/(nS_XX))·Σ(xᵢ−x̄) + …
```
$\sum(x_i-\bar x)=0$이라 **최종 결과 $\frac1n+\frac{\bar x^2}{S_{XX}}$는 옳다.** 다만 `[[Durbin-Watson 검정]]`이 "계수 2를 절대 떨어뜨리지 말 것"을 자기 약점으로 기록한 바로 그 유형이라 고쳐 둘 값이 있다.

#### F-10. `Durbin-Watson 검정.md:185` — "엄밀히는 베타족"은 부정확

> "이름 없는 '이차형식 비'의 분포 (자유도 미분할이라 **엄밀히는 베타족**; $F$는 그 단조변환)"

$d=\dfrac{\varepsilon'MAM\varepsilon}{\varepsilon'M\varepsilon}=\dfrac{\sum_j\nu_j w_j^2}{\sum_j w_j^2}$ 는 $MAM$의 고윳값 $\nu_j$가 **두 값만 가질 때에만** 베타가 된다. 일반적으로는 베타가 아니며, 그래서 같은 절 (4)에서 "닫힌형 없음 → Imhof 수치적분"이라고 옳게 이어진다(**같은 절 안에서 앞뒤가 충돌**). 베타 형태는 Durbin–Watson(1951) 이래 널리 쓰이는 **근사**다.

**조치**: "엄밀히는 베타족" → "베타분포로 **근사**하는 관행이 있다(Durbin–Watson 1951). 정확분포는 고윳값에 의존해 Imhof로 계산한다"로 한 줄 수정.

#### F-11. `누락변수 편의와 유의성 반전.md` §3 — 모형 명세가 바뀌는데 표시가 없음

§0은 6변수 모형(`score ~ .`, df 353, index p=0.0345)을 말하고, §3은 **F(5,354)=1.618**을 "exam34 문제4의 실제 상황"이라 부른다. 분자 자유도 5는 **index를 뺀 5변수 모형**이다(재계산: F(5,354)=1.618 → p=0.1544로 노트의 0.154와 일치하므로 계산 자체는 옳다). 어느 모형인지 한 줄 명시가 없어 §0과 모순처럼 읽힌다.
