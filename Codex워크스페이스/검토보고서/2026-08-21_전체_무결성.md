### [P1] 개념 연결 도식의 위키링크가 코드 블록 안에 있어 비대화형이며 일부는 중첩 구문으로 손상됨

- 위치: `01_Concept_Connection_Curriculum.md:111-123, 166-172, 202-206, 252-254, 292-298, 343-344`.
- 근거: 해당 도식들은 fenced code block(````...````) 안에 `[[...]]`를 넣고 있다. Obsidian은 코드 블록의 텍스트를 위키링크로 해석하지 않는다. 또한 `:116-117`, `:166-168`, `:202-203`, `:252-254`, `:292-294`, `:343-344`에는 `[[... [[...]] ...]]` 형태의 중첩 대괄호가 있어 링크 대상 문자열 자체도 손상된다.
- 영향: 전체 커리큘럼의 핵심 개념 사슬이 시각적으로는 링크처럼 보이나 클릭으로 이동할 수 없고, 연계 노트가 존재하더라도 도식에서 탐색할 수 없다.
- 권장 조치: 도식의 링크를 코드 블록 밖의 Markdown 목록·표로 분리하거나, 각 노드를 독립적인 단일 위키링크로 재배치한다. ASCII 도식을 유지한다면 링크가 아닌 일반 텍스트로 명확히 표기한다.
- 상태: open
